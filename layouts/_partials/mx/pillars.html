Why Praxis

A governed entry point
to your models and tools.

Translate provider APIs, stream large payloads, and stop unwanted requests before they reach a model, on a Rust core you can extend.

{{- /* ------------------------------------------------------------ ai */}}

One gateway for your model traffic Alpha

The gateway classifies OpenAI Responses, Chat Completions and Anthropic Messages traffic, routes by API format, model or MCP tool name, and translates between provider APIs, streaming included.

Gateway capabilities →
  • {{ $check }}Anthropic Messages clients on Chat Completions-compatible backends such as vLLM
  • {{ $check }}Chat Completions adapted to Azure OpenAI, Bedrock Converse and Vertex AI Gemini, within their documented limits
  • {{ $check }}MCP and A2A classification and routing
  • {{ $check }}Token usage extracted across supported provider formats
{{- /* ------------------------------------------------------------ secure */}}

Governed before it reaches a model

Token ceilings, token rate limits and external guardrail providers sit in the request path. Underneath, the foundation treats security as a primary design constraint: secure defaults, upstream TLS verification, and it fails closed on ambiguous configuration.

Security hardening guide →
  • {{ $check }}unsafe_code = "deny" across the workspace
  • {{ $check }}Rustls: no OpenSSL, no C FFI in the TLS path
  • {{ $check }}Root execution rejected; admin endpoints stay on loopback
  • {{ $check }}Token ceilings, token rate limits and guardrail providers
{{- /* ------------------------------------------------------------ payload */}}

Big bodies, inspected without stalling

Each filter declares how it reads a body. Stream passes chunks straight through. StreamBuffer hands chunks to a filter as they arrive while holding them back from the upstream, then releases the buffer once the content checks out.

Payload processing →
  • {{ $check }}Peek-then-stream for body routing, JSON-RPC parsing and payload scanning
  • {{ $check }}AI request classification builds on the same StreamBuffer model
  • {{ $check }}Global hard ceilings on request and response size
  • {{ $check }}gzip, brotli and zstd response compression
{{- /* ------------------------------------------------------------ speed */}}

A Rust core you can build on

The gateway runs on a proxy foundation written in Rust. Bodies stream by default: each chunk goes to the next hop as soon as it arrives. Implement the HttpFilter trait in your own crate and compile it in next to the built-in filters.

Extend the gateway in Rust →
  • {{ $check }}Zero-copy streaming by default
  • {{ $check }}Round-robin, least-connections, consistent-hash, P2C, weighted
  • {{ $check }}Active and passive health checks, circuit breaker
  • {{ $check }}Custom filters compiled into your own build
