# IBM Plex font assets

The self-hosted WOFF2 files in this directory are unmodified IBM Plex Sans and IBM Plex Mono assets from the official [IBM Plex repository](https://github.com/IBM/plex). The upstream revision was not recorded when these files were copied; the SHA-256 values below identify the exact files in this website source tree.
